BMI Calculator – Python Project
This is a simple yet effective BMI (Body Mass Index) Calculator built using Python. The project takes a user's weight and height as input and calculates their BMI to help assess whether they are underweight, normal weight, overweight, or obese based on standard BMI categories.

🔍 Features
User-friendly command-line interface

Accepts both metric (kg, meters) and imperial (lbs, inches) units

Categorizes BMI results based on WHO standards

Input validation for accurate results

Clear output display with helpful feedback

📦 Requirements
Python 3.x

No external libraries are required—this project uses only standard Python modules.

🚀 How to Run
Clone the repository or download the .py file.

Open a terminal and navigate to the project directory.
